# 🏥 Hospital Management System

A modern Hospital Management System built with React and Vite for managing patients, doctors, appointments, and medical reports.

## ✨ Features

- 🔐 Admin Login
- 📊 Dashboard
- 👥 Patient Management
- 👨‍⚕️ Doctor Management
- 📅 Appointment Management
- 📄 Medical Report Management
- 🔎 Search
- 📱 Responsive UI

## 🛠️ Technologies

- React
- Vite
- JavaScript
- HTML
- CSS
- LocalStorage

## 🚀 Run Locally

```bash
npm install
npm run dev
